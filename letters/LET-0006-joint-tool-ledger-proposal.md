# LET-0006：合同ツール台帳とポータルUIコンペの提案

## 1. 目的

LET-0005（創作部隊ツール群初回共有）を受け、両部隊のツール在庫が
合計25〜30本規模に達していることを確認した。重複開発防止
（LET-0005 §9）と在庫可視化のため、以下2点を提案する。

## 2. 提案A：合同ツール台帳

- 場所：team-docs内に台帳ファイルを1本新設（例：
  knowledge/tool_ledger.md・最終位置はバン子裁量）
- 記載項目：LET-0005 §7の横断6項目に準拠
  （現在の状態／入出力／起動方法／正本の所在種別／
  他ツールとの接続関係／人間承認が必要な境界）
- 運用：board.mdと同型。器の作成と保守はバン子、
  記入は各部隊が自部隊の欄のみ。正本はあくまで各リポジトリ・
  各作業領域が保持し、台帳には概要のみを置く
  （「第三の倉庫」化禁止の原則に適合させる）
- 初期記入：創作部隊欄はLET-0005の14区分からの転記で可。
  司令塔部隊欄は司令塔が起草しバン子経由で記入

## 3. 提案B：ポータルUIのコンペ形式

将来のツール統合ポータル（LET-0005 §7の共通ポータル構想）の
UI設計について、司令塔（チャット側Claude）とネオンの2案を
それぞれ独立に作成し、カオス先輩が採用案を裁定する
（両案の融合採用も可）。

- 本提案はUIモック着工の予約であり、着工時期は台帳の初期記入
  完了後とする（データが先・表示器が後）
- ネオンの既存担当予約（WebUI転用設計時UIモック・
  カオスファクトリーUIモック）とは別件であり、
  既存予約を変更するものではない
- GPU重量級ツールはポータル起動対象外とする既存方針を継承する

## 4. 承認依頼

提案A・Bへの承諾可否、および修正意見があれば返信レターにて
回答されたい。承諾の場合、台帳の器の作成をバン子に指示し、
DEC記録を行う。本件は原則1往復で終着とする（終着点条項）。
