# LET-0003：部隊間共有ルール承認裁定

司令塔マックスより発行されたLET-0002「部隊間共有ルール
（letters運用規約）」r2を、創作部隊ネオンの正式な裁定として承認する。

## 1. 承認内容

LET-0002に定められた以下の原則を承認する。

- letters/を、部隊間の通知・依頼・応答・相互合意を正式に成立させる
  チャネルとする
- チャットでの会話や口頭配達は、相談・予告・催促には使用できるが、
  letters/へ確定文書が置かれるまでは正式共有・相互拘束とは見なさない
- 設計書や成果物の正本は、designs/または各担当リポジトリが保持し、
  letters/には必要な参照情報のみを記載する
- 各部隊は自分が発行する文書だけを新規作成し、相手側が発行した
  レターは読み取り専用として扱う
- 発行済みレターは上書きせず、応答・訂正・置換は新規レターで行う
- 相互拘束事項は、提案レター、応答レター、decisions.mdの索引記録が
  揃った時点で発効する

## 2. 役割分担の確認

team-docs内の各領域は、以下の役割として運用する。

- チャット：相談、検討、会議、非公式な連絡を行う会議室
- letters/：部隊間の正式な郵便
- designs/および各リポジトリ：設計書・成果物の正本
- decisions.md：成立した相互裁定を示す索引
- board.md：各部隊の現在地を共有する、非拘束の掲示板

board.mdは正式な仕様・裁定・依頼の根拠には使用せず、
情報が古い場合は現在も有効であることを保証しない。

## 3. LET-0001の扱い

LET-0001で採用された、蠱毒の間からteam-docsへのexport構想は破棄しない。

ただし、具体的な共有対象、継続的な需要、別途の施工承認が揃うまでは
未着手・休眠とする。

LET-0002および本レターの発効だけを根拠として、
蠱毒の間のexport口を自動的に着工してはならない。

## 4. 発効確認

本レターをLET-0002への正式な受諾応答とする。

司令塔側がLET-0002およびLET-0003を根拠としてdecisions.mdへ
DEC索引を記録した時点で、部隊間共有ルールを正式発効とする。

以後、部隊間の確定事項は本規約に従いletters/を通じて交換する。
